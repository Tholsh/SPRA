# SPRA v0.2.1

Local release draft for review; nothing published to GitHub.
Target: `v0.2.1` at `7e861e1dbb0312baf05be39157b5f1a4a70f8001`.

- Halfar's codec fixes: decode limits, canonical `--strict` mode, automatic
  six-bit fallback, and revised xz defaults.
- Optional SPBE byte-pair compression, now streaming by default; whole-file
  mode remains available. Recipe containers were not imported.
- Header-first SPRA streaming with supplied metadata, a measurement command,
  and raw-SPRA wrapper output.
- Paint-waste tuples now match the codec's signed offsets.
- Recursive archive decompression and consistent tool/documentation names.
- WSL/Linux Bash workflow, `make`/`make test`, and shell-only live-pipeline tests.
  PowerShell launchers and tracked local editor/Git settings were removed.

SPRA remains format 0.2; legacy 0.1 decoding is supported. BPE is optional and
does not guarantee smaller archives. Default xz decoding needs about 257 MiB;
use explicit xz options for other memory/compression tradeoffs. New-word
encoding requires a measurement pass unless all header metadata is supplied.

Validation recorded during development: all seven Linux binaries built;
four regression suites, verifier self-tests, corpus/archive smoke checks,
and live-input round trips passed in Ubuntu WSL 2. The live test also rejected
a producer that buffered until EOF.
